# Portfolio personal – Uriel Palacio

Portfolio web con temática de tecnología, informática y automovilismo, desarrollado con HTML5 y CSS3.

## Archivos
- `index.html`: estructura y contenido del portfolio.
- `css/estilos.css`: diseño y adaptación a pantallas pequeñas (debe conservarse en esta ruta).
- `assets/img/`: carpeta para imágenes propias o autorizadas.
- `bitacora_ia.md`: registro del uso de inteligencia artificial.

## Contenido
El portfolio presenta a Uriel Palacio, estudiante de 6.º año de secundaria con orientación en Informática. La sección de proyectos muestra tres experiencias escolares:
- **ConvivIA:** trabajo con Python, Tkinter, SQLite y arquitectura MVC; se describe la participación en la comprensión de la estructura y las pruebas de operaciones CRUD.
- **Arduino y sensores:** exploración de conexiones y alimentación de un sensor de distancia y motores.
- **Edición audiovisual:** planificación de capas de audio, selección de efectos y sincronización con un fragmento de video.

Las descripciones distinguen las actividades de aprendizaje de los productos terminados y no afirman resultados que no hayan sido confirmados.

## Identidad visual automotriz
Se conserva la temática automotriz de la versión original, con referencias a Ferrari, BMW, Volkswagen, Porsche y Volkswagen Scirocco. La imagen de portada se espera en `assets/img/banner-automotor.png`.

## Antes de publicar
1. Comprobar que estén presentes `css/estilos.css` y `assets/img/banner-automotor.png`.
2. Revisar el portfolio en computadora y celular.
3. Agregar un correo o medio de contacto si se desea hacerlo público.
4. Revisar que cada descripción represente fielmente el estado real de cada trabajo.
